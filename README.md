# Scientific Calculator

Modern scientific calculator for engineering, mathematics, and technical work.

## Features

- Scientific and engineering calculations
- Statistics and probability
- Equation solving
- Matrix, vector, and complex-number calculations
- Numerical calculus and function tables
- Base-N calculations
- Unit conversion and engineering constants
- Calculation history, memory, and variables
- Keyboard support
- Responsive UI
- Offline-capable PWA

## Tech Stack

- React
- TypeScript
- Vite
- math.js
- Vitest

## Development

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite.

## Commands

```sh
npm run dev      # Start development server
npm run build    # Type-check and create production build
npm run preview  # Preview production build
npm test         # Run tests
```

## Production Build

```sh
npm run build
```

Vite writes production files to `dist/`.
